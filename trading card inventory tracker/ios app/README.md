# iOS App

Starter SwiftUI structure for the Trading Card Inventory Tracker iOS experience.

## Current Scope

- Add graded cards manually
- View collection value and gain/loss
- Refresh prices through a valuation provider abstraction

## Files

- `Sources/App/`: app entry point
- `Sources/Models/`: card and portfolio models
- `Sources/Services/`: valuation provider protocol and mock service
- `Sources/ViewModels/`: portfolio state management
- `Sources/Views/`: dashboard and add-card UI

## Next Step

Create a new iOS app target in Xcode and copy these files into it.
