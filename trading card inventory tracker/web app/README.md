# Web App

Starter browser app for the Trading Card Inventory Tracker.

## Current Scope

- Add trading cards and PSA grades
- Track current portfolio value
- Track collection gain/loss
- Refresh mocked market valuations
- Store holdings locally in browser storage

## Files

- `index.html`: app shell
- `styles.css`: layout and visual system
- `app.js`: state, rendering, and valuation refresh logic
